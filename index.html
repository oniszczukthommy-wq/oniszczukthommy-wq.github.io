PROJECT 01 / CREATIVE♫

Osmanthus

AI 音乐创作工作台

把音乐想法变成可以试听、修改和导出的歌曲。围绕中文流行歌曲创作，衔接歌词、两版歌曲对比、分轨修改与乐谱准备，并探索 MV 制作。

音乐创作分轨编辑人在回路

歌曲与音频编辑流程已验证；完整 MV 流程仍在验证。

公开项目介绍 ↗源码与运行说明 ↗
展开案例 · 流程与产品取舍

为谁解决什么问题

懂一些音乐、希望借助 AI 完成作曲与编配的创作者，也面向普通创作爱好者。

核心流程与能力

  • 确认歌词后再生成，对比两版候选，由用户试听选择。
  • 对话与手动操作编辑同一份分轨工程，支持撤销、重做与 WAV / MP3 导出。
  • 准备演唱谱并人工复核；MV 画布组织分镜、素材、字幕与视频导出。

产品取舍

把创作分成可确认、可试听、可修改的步骤。歌词和歌曲选择由人决定，避免把一次模型生成直接当成最终作品。

如何体验

公开介绍与源码可查看。完整体验依赖本机工具、模型与自行配置的 API；也可以联系我了解原型体验。

当前边界：自动谱面仍需复核，分轨可能串音。完整 MV 稳定性、Windows 实机及部分模型依赖仍需验收。

为谁解决什么问题

需要独立推进研究、需求与文档工作的产品经理和个人产品开发者。

核心流程与能力

  • 多路联网产品拆解、需求访谈与资料整理。
  • PRD 与技术方案的导入、编辑、版本管理和全文搜索。
  • AI 修改展示差异，确认后保存新版本；支持任务管理与回收站恢复。

产品取舍

把 AI 建议与正式文档之间的确认步骤做成产品机制，保留版本和关联产物，便于追溯和恢复。

如何体验

公开展示仓库提供流程和能力介绍；完整源码与个人业务数据保持私有。体验可通过邮箱联系。

当前边界：复用 DeepSeek Harness 与 Agent Blueprint，方法与部分交互参考 Simin Lab。任务标记完成不代表代码已经执行。

公开项目介绍 ↗
展开案例 · 流程与产品取舍

为谁解决什么问题

喜欢推理、角色对话和互动叙事的玩家。

核心流程与能力

  • 三种场景和三档难度，分别配置 3 / 4 / 6 位 NPC。
  • AI 生成案件后执行结构校验，约束角色与证据关系。
  • NPC 仅持有部分事实，物证和结案判定构成完整玩法循环。

产品取舍

让 NPC 的知识保持局部，玩家需要比较不同口供与物证。案件生成增加结构约束，减少线索关系自相矛盾。

如何体验

公开仓库展示原创玩法与产品流程，完整开发仓库保持私有。没有模型配置时可使用本地演练案件。

当前边界：实际美术与游戏体验以当前原型为准；真实 AI 案件和不同设备的浏览器体验仍需持续验证。

PROJECT 04 / CREATIVE▤
提出问题 → 检索证据 → 核对来源 → 收藏 / 导出

Shot Agent

影视镜头检索与问片助理

用一句话寻找电影、画面或台词，回答附带可以核对的来源。内置两部 CC BY 3.0 开源电影的 244 个镜头，支持筛选、切片和参考板。

证据检索244 个镜头Python / FastAPI

公开源码与在线演示；线上不含影片本体。

源码与说明 ↗在线演示 ↗
展开案例 · 流程与产品取舍

为谁解决什么问题

需要寻找影视参考、回忆台词出处，或整理镜头与片单的用户。

核心流程与能力

  • 问片通过搜索、字幕和影片信息工具形成带出处的候选。
  • 镜头库按画面属性筛选，台词与时间轴对齐，支持 MP4 / GIF 切片。
  • 参考板导出与浏览器本地片单；片单可用 JSON 备份。

产品取舍

引用 URL 只使用工具实际返回的来源，评分和观看渠道另做核对。将本地规则检索与模型编排问片分开，保证边界清晰。

如何体验

可查看公开源码及部署说明，或打开在线演示。免费演示实例可能需要唤醒；播放和切片需本地准备授权影片。

当前边界：模糊画面描述仅提供候选，截图找片尚未实现。片单按浏览器保存，不跨设备自动同步。

为谁解决什么问题

需要管理多份视觉素材、生成任务与不同尺寸导出的内容创作者。

核心流程与能力

  • 项目、素材、图层、风格模板和导出规格管理。
  • 图像、视频、导出三条任务泳道，支持优先级、暂停、取消和重跑。
  • 任务持久化、崩溃恢复、生成产物回滚及审计记录。

产品取舍

先验证任务生命周期、恢复与画布衔接，让失败和中断有明确处理路径，再接入真实生成模型。

如何体验

公开仓库提供产品介绍，完整源码与个人素材保持私有。可联系我了解流程演示。

当前边界：当前图像与视频输出是 Mock 占位内容，不能作为真实模型效果展示；预留的模型适配接口尚未完成集成验收。

把虚拟琴弦、和弦切换、弹唱谱和录音放进浏览器。可以用键盘、触屏或摄像头手势演奏，也可以把歌声和吉他混音保存。

公开项目介绍 ↗
展开案例 · 流程与产品取舍

为谁解决什么问题

希望在浏览器中练习和弦、弹唱，或尝试不同输入方式的音乐爱好者。

核心流程与能力

  • 键盘切换和弦与扫弦，鼠标 / 触屏逐弦演奏。
  • 摄像头识别手势，选择和弦并触发扫弦。
  • ChordPro / JSON 导入、编辑、移调、全屏看谱与混音录制。

产品取舍

将演奏、读谱和录音组合在一个练习流程中。摄像头画面在浏览器内处理，麦克风与摄像头按需开启。

如何体验

公开仓库展示产品体验和实现边界，完整源码保持私有。原型体验可邮件联系。

当前边界：手机摄像头需要可信 HTTPS；自动和弦与时间轴仍需人工核对，实际手势稳定性取决于设备和环境。

让答案可以核对
